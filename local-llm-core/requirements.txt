# ─── [bitnet] — transformers-based BitNet fallback path ────────────────────────
# Only needed if bitnet.enabled: true AND the model doesn't route through
# bitnet.cpp directly. transformers is pinned to a specific range because the
# BitNet fallback depends on a specific fork/commit behavior — this is the one
# dependency in this repo that's deliberately version-locked rather than left
# to float.
# torch==2.4.1
# transformers>=4.46.3,<5.0
# accelerate==0.34.2
# bitsandbytes==0.43.3
